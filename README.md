## 🛠️ Stack Tecnológico Utilizado

* **HTML5:** Marcado semántico, metaetiquetas SEO y estructura accesible.
* **CSS3:** Variables nativas (`:root`), efectos *Glassmorphism*, transiciones y flexbox/grid.
* **Bootstrap 5.3:** Framework de soporte para rejilla responsiva (breakpoints móviles, tabletas y escritorio).
* **JavaScript (ES6+):** Animación matricial en Canvas, controlador del tema oscuro/claro y filtro DOM interactivo.
* **Librerías de Iconos:** Font Awesome 6 & Devicon.
